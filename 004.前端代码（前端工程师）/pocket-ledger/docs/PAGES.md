# 页面跳转地图

> 本文档列出 5 个页面之间的跳转关系，以及与 PRD 章节的对应。

## 页面索引

| Page Key | 文件 | 说明 | PRD |
| --- | --- | --- | --- |
| `index` | `index.html` | 登录 / 注册（默认入口） | V1.0.1 F9 / F10 / F12-A |
| `home` | `home.html` | 首页（记账 + 今日明细） | V1.0 F1 / F3 |
| `statistics` | `statistics.html` | 统计报表 | V1.0 F4 |
| `budget` | `budget.html` | 预算管理 | V1.0 F5 |
| `profile` | `profile.html` | 我的（含 V1.0.1 F11 / F12-D） | V1.0 F6 / F7 |

## 入口与守卫

| 入口 | 行为 |
| --- | --- |
| 浏览器打开 `index.html` | 已登录 → 自动跳 `home.html`；未登录 → 显示登录/注册 |
| 浏览器直接打开 `home.html` | 未登录 → 自动跳 `index.html`；已登录 → 进入首页 |
| 浏览器直接打开 `statistics/budget/profile.html` | 同上（业务页统一受保护） |

> 守卫逻辑见 `assets/js/guard.js`。

## 各页内的跳转

### index.html
- 「登录 / 注册」Tab 切换（不离开页面）
- 「忘记密码？」按钮 → 弹出三选一卡片：
  - 「我之前导出过备份」→ 打开「从备份恢复」弹窗
  - 「我想保留这个用户名」→ 打开「账号重置」弹窗
  - 「我重新注册一个」→ 切到「注册新账号」Tab
- 「立即备份」（F12-E 浮层）→ 触发 JSON 下载

### home.html
- 顶部「记一笔」→ 写入数据 → 重渲染「今日明细」
- 「今日明细」行 → 打开「详情弹窗」（PRD F8：编辑/删除）
- 侧边栏 / 顶栏 → 跳其他页面

### statistics.html
- 顶部 Tab（日/周/月/年）→ 切换聚合粒度
- 柱状图 / 环形图 / Top 排行榜点击 → 联动到底部「明细列表」（PRD F4 验收：跳转到筛选后的明细列表）

### budget.html
- 「设置新预算」按钮 → 打开弹窗 → 保存后刷新进度条
- 「测试 80% 提醒 / 测试 100% 超支」按钮 → Toast 演示提醒
- 分类卡片「移除」按钮 → 删除该分类预算

### profile.html
- 「立即导出 JSON 备份」→ 下载文件（PRD F7）
- 「导出 CSV 报表」→ 下载文件（PRD F7）
- 「从备份恢复」上传区 → 解析 + 选择策略（覆盖 / 合并 / 取消）
- 「编辑资料」→ 修改 displayName
- 「退出登录」→ 二次确认 → 清 `ma_current_userId` → 跳 `index.html`
- 「新建共享账本」→ 写入新账本（共享类型，本地原型）
- 「6 位邀请码加入」→ 输入框自动跳格（PRD F6 UI 占位）
- 「新增分类」→ 写入用户自定义分类
- 顶部「立即备份」banner → 同「立即导出 JSON 备份」
