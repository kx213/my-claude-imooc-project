## 2. 产品概述

### 2.1 一句话定义
一款轻量级的个人/小微记账 Web 应用，帮助用户用最短时间记录每一笔收支，并通过清晰的统计与预算提醒，建立健康的消费习惯。

### 2.2 产品愿景
让记账这件事变得「不费力、不费时、不费脑」——从打开到记完一笔账，10 秒内完成。

### 2.3 核心价值主张
- **极简录入**：默认参数智能填充，连续记录无需重复操作。
- **一目了然**：日 / 周 / 月汇总 + 分类图表，3 秒看懂钱花在哪。
- **安心可控**：预算 + 超支提醒，避免月末才发现预算超支。
- **数据自主**：本地存储 + 一键导出，数据归用户所有。

### 2.4 产品目标
| 目标 | 说明 |
| --- | --- |
| 业务目标 | V1.0 上线后，DAU 留存 ≥ 60%（30 日） |
| 用户目标 | 每次记账 ≤ 10 秒；月度复盘 ≤ 30 秒 |
| 产品目标 | 核心流程可用率 ≥ 99.5%；P95 加载 ≤ 1.5s |

## 3. 目标用户与场景

### 3.1 用户分层
V1.0 主服务以下三类用户，按优先级排序：

| 优先级 | 用户类型 | 占比预期 | 关键诉求 |
| --- | --- | --- | --- |
| P0 | 个人记账者（单身 / 学生 / 上班族） | 60% | 快速、简单、能看趋势 |
| P1 | 家庭 / 情侣共同账本 | 25% | 多人协作、分类明确、可导出对账 |
| P2 | 小微企业主 / 个体户 | 15% | 简单流水、收入支出分离、可导出做账 |

### 3.2 典型用户画像

**画像 A：小李（25 岁，上班族）**
- 每月工资到手 8000，房租 2500，生活开支 3000 左右。
- 痛点：经常不知道钱花到哪了，月底才发现超支。
- 期望：能快速记一笔、看本月花了多少、设个总预算。

**画像 B：王女士（35 岁，全职妈妈）**
- 管理家庭 3 口人的日常开支，需要和老公对账。
- 痛点：传统记账 App 太复杂，希望简单到父母也能用。
- 期望：账本共享给家人、分类清楚、能导出 Excel。

**画像 C：陈老板（40 岁，个体餐饮店）**
- 用个人账户收付款，需要区分经营性收支与家庭开支。
- 痛点：商业记账软件太贵，Excel 又容易乱。
- 期望：能把经营和生活分开统计，能导出流水给会计。

### 3.3 核心使用场景

| 场景 | 触发时机 | 用户行为 | 期望结果 |
| --- | --- | --- | --- |
| S1 随手记一笔 | 消费发生时 | 打开首页 → 输入金额 → 选分类 → 保存 | ≤10 秒完成 |
| S2 看今日花了多少 | 晚上睡前 | 打开首页 / 统计页 | 一眼看到今日总额 |
| S3 月末复盘 | 月底 / 发工资前后 | 进入统计页切换「月」视图 | 看分类占比、趋势，判断是否超预算 |
| S4 设置预算 | 月初 | 进入预算页 → 设置总额或分类预算 | 后续超额有提醒 |
| S5 多人协作 | 家庭成员各自记账 | 共享账本 / 邀请码 | 同一账本下所有人可记、可看 |
| S6 导出做账 | 每季度 / 年底 | 导出 CSV | 一份完整流水表 |

### 4.2 功能详情

#### F1：快速记账
| 维度 | 详细说明 |
| --- | --- |
| 入口 | 首页主按钮「+」/ 底部固定「记一笔」 |
| 表单字段 | ①类型（支出 / 收入，默认支出）；②金额（必填，数字键盘，保留两位小数）；③分类（必填，下拉选择）；④时间（默认当前，可改）；⑤备注（可选，≤50 字） |
| 交互 | 提交成功后保留当前类型与分类，方便连续记录同类型；金额输入框自动聚焦；保存后显示轻提示「已记 ¥XX」并震动反馈（移动端） |
| 异常 | 金额为空 / ≤0 → 按钮置灰；分类为空 → 引导先创建分类 |
| 验收 | 从首页打开到记账完成，操作步骤 ≤ 4 步；耗时 ≤ 10 秒 |

#### F2：分类管理
| 维度 | 详细说明 |
| --- | --- |
| 预设支出分类 | 餐饮、交通、购物、娱乐、居家、通讯、医疗、学习、社交、其他 |
| 预设收入分类 | 工资、奖金、报销、转账、投资、其他 |
| 自定义 | 用户可新增（图标 + 名称）、编辑、删除自定义分类；预设分类不可删除可重命名 |
| 排序 | 拖拽排序，记录过的分类置顶 |
| 验收 | 新增 / 编辑 / 删除分类在 3 步内完成 |

#### F3：收支明细列表
| 维度 | 详细说明 |
| --- | --- |
| 默认展示 | 按时间倒序，按「日」分组 |
| 筛选 | 时间范围（日 / 周 / 月 / 自定义）、类型（支出 / 收入）、分类（多选） |
| 搜索 | 备注关键字模糊匹配 |
| 操作 | 点击单条 → 进入详情页，可编辑或删除（删除前 Toast「再点一次确认」） |
| 性能 | 单账本 ≥ 5000 条记录时滚动流畅（≥50fps） |
| 验收 | 任意筛选组合都能正确返回结果；搜索响应 ≤ 300ms |

#### F4：统计报表
| 维度 | 详细说明 |
| --- | --- |
| 视图 | 日 / 周 / 月 / 年 四个 Tab |
| 顶部数据卡 | 期间收入、支出、结余（结余 = 收入 - 支出） |
| 图表 1 | 支出分类占比（环形图） |
| 图表 2 | 每日收支趋势（折线 / 柱状，支出 / 收入分别展示） |
| 图表 3 | 分类 Top 排行（条形图，默认 Top 5） |
| 交互 | 点击图表元素 → 跳转到筛选后的明细列表 |
| 验收 | 数据与明细列表 100% 一致；图表加载 ≤ 1s |

#### F5：预算管理
| 维度 | 详细说明 |
| --- | --- |
| 预算类型 | 总预算（整账本）、分类预算（按分类） |
| 预算周期 | 月度（V1）/ 周度（V1.1） |
| 提醒规则 | ①达到 80% 提示一次；②达到 100% 强提醒一次；③超支后在每次记同分类账时附带提示 |
| 提醒方式 | Web 内 Toast / 通知中心；移动浏览器可借助 Notification API |
| 验收 | 设置预算 → 故意制造超额 → 触发对应提醒；周期切换时数据正确归档 |

#### F6：多账本
| 维度 | 详细说明 |
| --- | --- |
| 账本类型 | 个人账本 / 共享账本（家庭、生意） |
| 切换 | 顶部下拉切换，全局生效 |
| 共享账本 | V1 通过「邀请码」机制：创建者生成 6 位邀请码，对方输入后加入；同一账本数据隔离 |
| 同步 | V1 仅共享账本支持云端同步（轻量后端）；个人账本可选本地 / 云端 |
| 验收 | 创建 → 邀请 → 加入 → 双方都能看到对方记录；账本数据互不干扰 |

#### F7：数据导出
| 维度 | 详细说明 |
| --- | --- |
| 格式 | CSV（UTF-8 with BOM，Excel 友好） |
| 范围 | 按账本、按时间范围、按类型导出 |
| 字段 | 时间、类型、金额、分类、备注 |
| 触发 | 「我的」→「数据导出」→ 选择条件 → 下载 |
| 验收 | 导出文件用 Excel 打开字段不乱码；行数与筛选条件一致 |

#### F8：记录编辑 / 删除
| 维度 | 详细说明 |
| --- | --- |
| 编辑 | 修改任意字段，保存即生效；记录上显示「已编辑」标记 |
| 删除 | 触发后显示 5 秒倒计时 Toast「再点一次确认」，过期不删 |
| 验收 | 编辑 / 删除后明细与统计同步更新，无需手动刷新 |

## 7. UI / UX 设计原则

### 7.1 视觉风格
- **配色**：主色温和清新（建议浅蓝绿 #4FB3A9 或暖橙 #F5A25D，避免大红大紫）；金额数字突出（红色 = 支出，绿色 = 收入，需考虑色盲友好，建议辅以「-」「+」符号）。
- **字体**：默认系统字体；金额用等宽数字避免跳动。
- **留白**：移动端单屏只呈现一个主任务，列表项间距 ≥ 12px。

### 7.2 交互原则
- **零跳转录入**：首页即可完成记账，不进入二级页面。
- **智能默认**：上次使用的分类、类型作为下次默认值。
- **撤销友好**：删除提供 5 秒撤销窗口；编辑后展示「已修改」标记并可一键回滚。
- **空状态**：首次使用时给出引导示例（如「试试记一笔午餐：¥35」）。
- **错误兜底**：网络异常时本地暂存，恢复后自动重试。

### 7.3 移动端适配要点
- 所有按钮点击区域 ≥ 44×44px。
- 数字输入自动唤起数字键盘（`inputmode="decimal"`）。
- 适配 iOS 安全区域（`env(safe-area-inset-bottom)`）。
- 横屏锁定为竖屏。

## 9. 风险与边界

### 9.1 范围边界
**不做**：
- 银行 / 支付宝 / 微信账单自动导入。
- AI 自动分类、智能预算建议。
- 多币种、汇率换算。
- 商业财务报表生成（利润表 / 资产负债表）。

### 9.2 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 记账坚持不下来，3 天弃用 | 用户流失 | 引入轻提醒、连续记账天数成就、月度账单自动生成 |
| 多人协作数据冲突 | 数据错乱 | 共享账本使用「最后写入获胜」+ 操作日志 |
| 用户担心隐私 | 不敢用 | 默认本地存储；云端同步需明确告知并可一键关闭 |
| 移动浏览器适配坑多 | 体验差 | 锁定 2 款浏览器做主适配，其余 graceful degrade |

## 11. 验收标准（V1.0 上线门槛）

**功能性**
- [ ] 从打开首页到记完一笔账 ≤ 4 步操作、≤ 10 秒。
- [ ] 记账 → 明细 → 统计 三处数据 100% 一致。
- [ ] 设置预算后，故意超额能稳定触发对应提醒。
- [ ] 共享账本邀请码流程走通，双方数据双向可见。
- [ ] CSV 导出在 Excel 中字段不乱码，行数与筛选一致。

**体验性**
- [ ] 首次使用有引导；空状态有示例。
- [ ] 删除提供 5 秒撤销窗口。
- [ ] 移动端 3 款主流浏览器（Safari / Chrome / 微信内置）UI 无错位。

**质量性**
- [ ] 核心流程 P95 加载 ≤ 1.5s。
- [ ] 离线记账 100% 不丢失，恢复网络后自动同步。
- [ ] 关键页面通过无障碍基本检查（键盘可达 + 标签完整）。
